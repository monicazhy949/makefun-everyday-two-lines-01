A two-line explanation of rain for a 10-year-old: the sky wringing out a giant wet sponge. The first line gives the picture; the second line checks it — clouds really do soak up water and release it when they get too full, but nothing actually squeezes them, the drops simply get too heavy to stay up. Running `main.py` prints the entry and writes it to `/output/entry.txt`.

## Run it

```bash
python3 main.py
```
